# Wheat Mod Loader
**A mod loader for Counter-Strike 2**
> [!NOTE]  
> Wheat Mod Loader will **not** get you VAC banned as it forcefully uses `-insecure` (launch argument that disables VAC) everytime you launch CS2 with WML.

> [!WARNING]  
> WML doesn't support any projects that try to bypass/delete the `-insecure` check of the program.
